# Local AI Kit

Локальный помощник: Qwen3.5-9B Q4_K_M, история, документы, изолированные файловые инструменты и голос. `llama.cpp` собирается из исходников. Ubuntu 24.04/26.04 x86-64 и Windows 10/11 x64 без WSL.

## Автоматическая установка

### Ubuntu

1. Распакуйте архив в домашнюю папку. Папка программы: `~/local-ai-kit`.
2. Установка:

```bash
cd ~/local-ai-kit
bash ./local-ai.sh install --stage 4 --backend cpu
```

3. Запуск:

```bash
cd ~/local-ai-kit
bash ./local-ai.sh start --stage 4 --backend cpu
```

Откроется `http://127.0.0.1:8080`. Остановка — `Ctrl+C` в терминале запуска. Модели, окружение и данные: `~/LocalAISeries`.

### Windows

### Перед установкой на Windows 11
Smart App Control появился в Windows 11. Он проверяет подписи и репутацию программ и может блокировать компоненты проекта.
При блокировке: Безопасность Windows → Управление приложениями и браузером → Параметры интеллектуального управления приложениями → Выкл.
Другие компоненты безопасности не меняются.

Распакуйте архив в домашнюю папку. Откройте 64-разрядный PowerShell:

```powershell
Set-Location "$HOME/local-ai-kit"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\local-ai.ps1 install -Stage 4 -Backend cpu
.\local-ai.ps1 start -Stage 4 -Backend cpu
```

Файлы установки: `$HOME\LocalAISeries`.

## Ручная установка

Пошаговые инструкции по установке и настройке четырёх этапов хранятся в [docs/manual/](docs/manual/). В каждом файле есть варианты для Ubuntu и Windows.

## Этапы и настройки

| Этап | Доступно |
|---|---|
| 1 | Чат и настройки модели |
| 2 | Документы TXT/MD и явная память |
| 3 | Создание и чтение заметок через WASI; подтверждение записи |
| 4 | Распознавание речи и озвучка ответа |

Установка этапа 4 включает все этапы. Для запуска другого этапа измените его номер в команде `start`.

Кнопка **«Настройки»**: модель, контекст, рассуждения, лимит генерации и температура. В «Дополнительно» — потоки CPU и импорт модуля модели `.json`. Одновременно загружается одна LLM.

## Удаление

```bash
cd ~/local-ai-kit
bash ./local-ai.sh remove
```

```powershell
Set-Location "$HOME/local-ai-kit"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\local-ai.ps1 remove
```

Появится список ресурсов и запрос `DELETE`. После удаления установки удалите папку `local-ai-kit` через файловый менеджер. Скачанный ZIP-архив можно удалить после распаковки.
